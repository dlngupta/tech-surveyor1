# Tech Surveyor (Angular web)
npm install && npm start  → http://localhost:4200
Build: npm run build (output in dist/tech-surveyor/browser)

Surveyor Corner includes browser-side CSV/XLSX cleanup, editable resurvey notice drafts,
TIFF/TIF viewing, spreadsheet-to-KML joining, schematic CAD drawing with DXF/PDF export,
and land-area/length conversion. Files are processed locally in the browser. Notice text
is a general-purpose draft and must be reviewed against official requirements before use.
CAD drawings are schematic unless calibrated to a known plan scale.
